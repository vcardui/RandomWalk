# 🔀 **Random Walk**

A little turtle wandering randomly, leaving a colorful trail in its wake.

## 🎯 Objective

Experiment with Python Turtle library by positioning a little turtle object around the canvas randomly. In addition, trace it’s path by coloring each “step” with a different (as well random) color.
